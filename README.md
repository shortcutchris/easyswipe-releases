# EasySwipe Releases

Official release assets and signed Sparkle update feed for EasySwipe.

- Update feed: `https://raw.githubusercontent.com/shortcutchris/easyswipe-releases/main/appcast.xml`
- Downloads: `https://github.com/shortcutchris/easyswipe-releases/releases`
- Source code: maintained separately in a private repository

Only public release metadata, release notes, and notarized update archives belong here. Apple credentials, Developer ID material, and the private Sparkle EdDSA key must never be committed.
